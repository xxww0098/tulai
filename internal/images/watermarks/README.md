# 可见水印校准

模板用于识别固定角落的已知可见水印，不用于修改未匹配的图片。
PNG 为本项目经软件内 Ego 网页实际下载的纯黑校准图所提取的灰度蒙版。
算法参考与验证限制见项目 README。

2026-10-22 使用 tulai 当时内置的 Ego 官方 SDK，上传本地纯黑图并发送「请直接生成一张正方形的纯黑色图片，不要纹理，不要文字，不要边框，不要任何物体。」，通过网页普通下载入口取得以下校准图。扣除角落背景灰度后提取字形，未使用第三方模板素材。
