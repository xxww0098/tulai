使用当前源码启动 Windows app；测试素材为 `C:\Users\xxww\Desktop\test` 中的图片。网页任务均使用 tulai 管理的 Camoufox 和 Firefox 页面桥。脚本测试使用独立复制的测试资料；没有连接系统浏览器或外部调试端口。

## 改动

- 豆包新任务、空提示词回退及“默认词”按钮现在采用专用的纯二维画作提取词。其他平台继续使用通用重绘默认词。
- 将约 1600 字、逐次追加的提示词整理为约 530 字的执行顺序：选单幅主画、去载体与外框、保留画内内容、满幅输出。支持书封拼版、画框、屏幕、画架、填色辅助元素及彩色玻璃外沿的处理。
- 复测发现竖画可能被放在方形白底上，因此补充了比例不同时延展画内背景、不得用白边补比例的要求。
- 未改写的旧默认草稿升级；自定义要求保持原样。切换平台时仅替换尚未修改的默认词。
- 隐藏已经到期的额度/冷却错误提示，避免账号“空闲就绪”同时显示历史“额度用尽”。仍有效或没有恢复时间的错误继续显示。
