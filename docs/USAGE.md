# 使用指南

本文介绍应用界面、账号设置、图片生成、下载、本地批量工具、快捷键与数据迁移。安装和快速开始见[项目首页](../README.md)，核心架构与恢复规则见[核心任务执行与恢复设计](CORE_FLOW.md)。

## 界面总览

tulai 提供左侧可折叠导航栏（宽屏 `160px`，窗口窄于 `960px` 或手动折叠为 `52px` 图标栏）与主工作画布，涵盖全部 9 个视图与 2 个全局悬浮抽屉：

| 入口 | 快捷键 | 用途 |
|---|---|---|
| **图片生成** | `⌘/Ctrl+1` | 三种工作台模式：「批量洗图」「自由生图」「裂变图片」，展开侧栏可在其子菜单直接切换「豆包」/「千问」 |
| **浏览器** | `⌘/Ctrl+2` | 安装受管 Fingerprint 运行环境、管理账号池与独立代理 |
| **提示词** | `⌘/Ctrl+3` | 按「生图」「洗图」「裂变」筛选与编辑模板、配置全局后缀，一键填入自由生图 |
| **下载** | `⌘/Ctrl+4` | 网页、图片直链与 CSV / XLSX 批量抓图，支持托管指纹浏览器动态页面登录抓取 |
| **去重** | `⌘/Ctrl+5` | 三档 pHash 感知哈希相似图分组，复制每组最高分辨率原图并生成 CSV 报告 |
| **批量重命名** | `⌘/Ctrl+6` | 查找替换、插入文本、序号重排、逐行编辑、AI 命名与一键撤销 |
| **图片编辑** | `⌘/Ctrl+7` | 三栏暗房：交互裁剪、尺寸与旋转、60fps 实时调色预览、原图对比分屏帘、配方与批量导出 |
| **设置** | `⌘/Ctrl+8` / `⌘/Ctrl+,` | 四个分类：「常规与输出」「账号与任务」「网络与高级」「关于与更新」 |
| **快速配置向导** | 首次启动自动弹出 | 引导选择平台、准备受管浏览器环境并登录首个账号 |

全局悬浮面板：

- **内置浏览器抽屉（`BrowserDrawer`）**：在工作台账号车道或「浏览器」页点击账号行的「可视」（出现验证码时点「去验证」）弹出可拖拽、可缩放的悬浮视窗，实时回传受管浏览器画面并转发点击、滚轮、键盘、中文输入法与粘贴操作。
- **运行日志抽屉（`LogDrawer`）**：点击左下角设置上方的「日志」按钮或按 `⌘/Ctrl+J` 开关暗色实时日志控制台，支持按级别（全部/调试/信息/警告/错误）和来源筛选、关键词搜索、暂停/继续跟随、点击展开详情、复制、导出和清空。

## 首次设置

第一次打开时会出现「快速配置向导」。第一步在豆包、千问里选一个，第一次只勾选选中的这个平台。接着确认并准备受管浏览器环境，随后进入首个账号登录步骤，在受管浏览器中完成登录后即可进入主界面，出图页停在刚设置的平台上。向导展示状态写在配置库里；之后即使没有可用账号也不会自动弹出。向导只在首次设置时出现，界面上没有手动重新打开它的入口；要再加平台或账号，在「图片生成」页的账号车道点「新建账号」或到「浏览器」页创建。

首次使用可在向导的浏览器准备步骤（「准备项目管控的浏览器环境」）或「浏览器」页按提示下载安装受管 Fingerprint（`fingerprint-chromium`）运行环境（向导里是「立即下载托管环境」，「浏览器」页是「下载安装 Fingerprint」）。安装后，在向导里点「下一步」，或在「浏览器」页点「新建账号」，然后在账号的专用受管窗口或内置「可视」抽屉完成登录。Windows x64 发布包内含 Node 和 Playwright 启动库，首次安装需联网下载指纹浏览器内核。Fingerprint 目前支持 Windows x64、macOS Apple Silicon（arm64）和 Linux x64。tulai 始终只使用项目管理的 Fingerprint，不连接系统浏览器或外部调试端口。

### 账号与代理

同一个平台可以添加多个账号，每个账号使用独立的 Fingerprint 资料目录与固定指纹种子。任务按账号状态和可用额度调度。某个账号出现额度用尽、请求过于频繁、未登录或验证码时，tulai 会把它标成冷却或已用尽，并改用下一个还能用的账号；其它账号还在时，这一批不会整批停掉。已经点过发送、但不确定有没有送出的任务不会换号重发。因额度用尽被停用的账号会记下恢复时间（当天用尽就等次日 0 点），到点自动回到可用状态，之前的额度提示和「清除冷却」一起消失。登录失效的账号显示为「需要登录」，在该账号点「可视」或「打开登录」完成登录，检测到登录成功后账号自动恢复可用。豆包和千问的受管账号均通过私有 CDP 管道与隔离世界页面桥控制页面。

生图和洗图默认使用无窗口的受管账号浏览器（可在「设置 → 账号与任务」开启「显示任务浏览器」改为有窗口运行），整批任务结束或停止后关闭，登录资料保留。需要人工验证时，在对应账号或洗图工位点击「去验证」/「可视」打开内置浏览器抽屉，直接在画面中完成验证或登录；完成后点击抽屉顶栏的「我已完成，继续任务」或关闭抽屉（`Esc`），任务继续。需要独立浏览器窗口时，可先停止该账号，再从「浏览器」页点「打开登录」启动。

账号可在「浏览器」页点击「代理」展开行内编辑器，设置独立 HTTP 或 SOCKS5 代理（留空则跟随全局代理）。HTTP 支持认证，SOCKS5 认证受 Playwright 限制而不支持。代理在下次打开账号时生效；运行中的账号不能修改。点击账号名还可就地重命名，支持多选后「批量打开」/「停止批量」。配置代理时会自动启用 `--webrtc-ip-handling-policy=disable_non_proxied_udp` 防止非代理 UDP 泄漏。技术范围、验证方式和已知边界见 [Fingerprint 受管浏览器说明](FINGERPRINT.md)。

## 图片生成

第一次打开先完成设置向导。在「图片生成」页面顶部切换「批量洗图」「自由生图」或「裂变图片」三种模式，各自保留当前草稿。展开左侧栏时可在「图片生成」子菜单直接切换「豆包」或「千问」（侧栏收起时，顶部模式栏右侧会出现平台下拉框）。页面左侧由三张卡片组成（模式设置与提示词、参考素材、左下角开始/停止按钮），右侧上方是该服务商的账号车道，下方是四阶段流水线与结果画廊。

「裂变图片」选择一张母图（也可开启「跳过参考图直接按提示词裂变」），默认指令要求保留可识别主体，并以四种构图、视角和配色分别生成一张图；可编辑共用指令，四种方向及母图约束仍会附加。每次使用当前选中的一个服务商，固定等待结果，最多保存每个方向的一张图到 `<目录>/裂变图片/<YYYY-MM-DD>/<母图文件名>_01.ext`；开启生图自动编号时也适用于裂变图片。完成后用 63 位 pHash 比较各结果的低频视觉结构，两两相似度超过 60% 的结果标记为「需核对」，可点击「重新生成」；重试会保留其他方向的结果和原有图片文件。更换母图会更新当前裂变素材，这一页的任务记录仍留在当前工作区。pHash 是结构相似度的近似，不能证明语义相似度或主体确实源于母图，请结合图片人工确认。服务商未返回图片、检测失败或结果过于相似时，不能保证一次得到四张通过检查的图。

1. 在左侧栏「图片生成」子菜单（或收起侧栏后的顶部下拉框）选择豆包或千问。豆包与千问为两个独立工作区页面，各自的参考素材、提示词草稿、出图结果队列、并发设置与会话进度完全隔离互不共享，每次开始只向当前所选服务商发送任务。
2. 自由生图包含「文生图」和「图生图」两种模式，两者保留各自独立的提示词草稿、模板状态与生成次数设置：
   - **文生图**：左栏隐藏参考图卡片以提供宽敞的多行编辑区，采用「一行一个提示词」形式并带行号提示（空行自动忽略），支持一键去重/清空、点击「导入TXT」或直接拖入 `.txt`/`.md` 文本文件导入（支持 UTF-8 / UTF-16 / GBK 编码，每行一条提示词）、设置「每条次数」（1–10 次）、套用已保存模板（多行模板可一键「转为逐行」或直接编辑解锁）、点击「结构化」拼装参数，以及勾选「追加后缀」拼接全局修饰词；直接拖入图片时会自动导入并切换至「图生图」。
   - **图生图**：支持导入单张/多张参考图或文件夹并设置「每图次数」（1–10 次），提示词支持在「统一描述」（整段多行指令发给每张参考图）与「逐行配对」（每行指令按顺序循环对应各张参考图）之间一键切换；未填提示词时输出文件名自动沿用参考图名称。
   - **输出规格与比例**：豆包、千问与千问国际统一提供网页端原生「输出尺寸」（原比例/自动比例及 1:1、4:3、3:4、16:9、9:16、3:2、2:3，不支持自定义像素），发图前直接点击网页原生比例菜单生效，不向提示词写入尺寸说明，生图过程中锁定不可变更且保存时不对网页成图做二次缩放或裁剪；选「原比例」时豆包切至「自动」，千问/千问国际在文生图分别默认 `3:4` / `16:9`、图生图/洗图自动贴合原图比例。
3. 批量洗图时在「参考素材」里点「选图」添加原图，或从同一菜单点「导入文件夹（一层）」收录整个文件夹（也可以直接拖入整个页面），默认折叠显示提示词摘要，点「编辑提示词」可展开修改，点「默认词」恢复默认；提供风格下拉框（保持原风格、像素、水彩、油画、动漫、扁平插画、国风水墨、黑白线稿、复古版画）与输出尺寸设置，去水印开关统一在「设置 → 账号与任务」中控制。「洗图」模板会尝试提取商品主图并还原为平面图案；风格选择会保留到下次使用，只影响新建洗图任务，重试保留原任务指令。在「提示词」页选中模板后点「填入工作台」，模板内容会填进自由生图的提示词框（下拉菜单也可直接指定「填入文生图」或「填入图生图」），工作区内之后的修改不会改变模板；「提示词」页按「全部」「生图」「洗图」「裂变」筛选模板，未分类的模板显示为「通用」。洗图进度随当前任务会话保存：重新打开软件后，已成功保存结果的原图不会再发送，再次点「开始洗图」只会处理剩余未洗原图；失败、停止或中断的图片仍算未洗。素材超过 6 张时，点「管理全部 N 张素材」打开「全部素材图片」，其中会标出「已洗图」和「洗图中...」，支持「清空已洗」以及逐张勾选「参与」或「移除」（只改动列表，不删源文件）。
4. 第一次使用按设置向导登录。要再加账号，在右侧账号车道点「管理」前往账号池添加。账号表格右上角内置「自动并发」开关与单平台并发上限（2–8，豆包与千问各自独立保存），并支持「全部启用」/「全部停用」、折叠为紧凑状态胶囊，以及单账号启停开关。
5. 点左下角的 **开始洗图** / **开始文生图** / **开始图生图** / **开始裂变**（或按 `⌘/Ctrl+Enter`）。任务会使用所选服务商的可用账号发送输入、等待结果并保存；运行中无法切换另一服务商（顶部或侧栏锁定另一平台）。右侧结果区按四阶段展示：
   - **正在加工**：每个并发账号以拟人化「小白洗图君」工位卡片展示原图、进度耗时与实时预览，支持「暂停动画」/「继续动画」并遵循系统减弱动态设置。
   - **等待加工**：按队列序号展示待派发缩略图，标记二次清洗项。
   - **需处理**：集中展示失败或需核对任务，支持单项操作或「重试失败」。
   - **已完成**：支持「小图」/「中图」视图切换、悬停大图预览、右键上下文菜单，以及「批量选择」（`Shift+点击` 连续范围多选），可将单张或多张结果「放回待洗队列（二次清洗）」并支持「撤销放回」。点击任意结果图打开大图 Lightbox，支持 `100%–400%` 滚轮/双击缩放与拖拽平移、可拖拽分屏帘的「对比原图」（`C`）、`←`/`→` 切换、复制路径、在文件夹中显示、替换原图与二次清洗。

输出目录可在设置中查看和修改。

自动并发开关与并发上限可在「图片生成」页右上角的账号表格内按平台独立调节（豆包与千问互不影响），重试、等待和去水印开关在「设置 → 账号与任务」。不改也能开跑。关闭并发时一次运行一批任务；开启时按可用账号自动安排，运行中也可实时调整并生效。豆包受管账号按相同提示词每 10 张原图发送一条消息，最后不足 10 张的一起发送。例如 23 张会分成 10、10、3 张。开启并发后，空闲账号可各自处理一批。账号剩余额度、手动设置的换号张数和审核重试可能限制单批张数。结果按豆包返回的源图关联保存，无法确认对应关系的图片放入「待核对」。

豆包所有账号的额度都用完时，程序会等已派发的任务结束，然后自动停止剩余任务。尚未处理的图片会保留，额度恢复后可以继续洗图。

结果都写进设置里的那一个输出目录。生图是 `<目录>/生图/<YYYY-MM-DD>/<提示词>_01.ext`，洗图是 `<目录>/洗图/<YYYY-MM-DD>/<原文件名>_01.png`。日期按保存时的本地日历，同一天的各次运行进同一个文件夹。一条回复里的多张图从 `_01` 接着编；文件已经存在就继续 `_03`、`_04`，不覆盖。提示词文件名取第一行，去掉 `\ / : * ? " < > |` 和不可见字符，最长 40 个字符；收成空串时用「文生图」。提示词和源图都空时不能开始，引擎返回「任务队列为空：请添加提示词，或添加源图片」。

在「设置 → 常规与输出」的「自动编号开关」里，可以分别勾选「自由生图自动编号」和「批量洗图自动编号」：文件按「前缀+补零序号」保存（如 `图001.png`），不再使用提示词或原文件名。前缀留空时只存序号（`001.png`）；「编号格式」里可以设置起始值和补零位数。同一个日期文件夹里同前缀的序号接着排；起始值只在当天还没有更大的号时生效，同样不覆盖已有文件。前缀里的路径非法字符会替换成 `_`。批量洗图无法确认对应关系的「待核对」结果仍按「批次N_未匹配」保存，不受此设置影响。

重试按阶段处理：确认发送成功后，等待或保存失败只继续获取原任务结果，不重新上传、标记或发送；已保存的部分图片保留且不重复落盘。发送动作已尝试但无法确认平台是否接受时，停止当前任务并显示错误，请先检查网页再决定是否重试。中断后重新打开时，当前任务没有完整提交上下文，需先核对，再主动选择是否重新生成。

调度优先分派空闲浏览器，同一浏览器账号内串行。「间隔(秒)」在同一实例的连续任务之间生效，冷却不会占用其他浏览器的并发名额，最后一项完成后不再等待。停止任务会取消本地执行、重试和间隔等待，并保留已保存结果；平台已接收的远端生成无法由本地停止操作撤回。

## 网页图片下载

在「下载」页左侧卡片逐行输入网页或图片地址（支持 `⌘/Ctrl+Enter` 快速提交）并选择顶部保存目录。点击「站点说明」可按网站名或页面类型查看采集范围。扫描深度为 1 时只检查当前网页；大于 1 时继续扫描同源链接。网页图片会按页面标题保存到独立目录，重复地址只下载一次；任务支持暂停、继续、失败重试、状态筛选与搜索。扫描最多处理 100 个网页，每页最多 8 MiB；达到上限或部分页面失败时会提示，已保存的图片保留。在下载页「抓取深度与过滤」卡片里（点「展开」）可以设置抓取深度、最小和最大文件大小、图片宽度和高度；0 表示不限，筛选条件随任务保存。

网页和表格任务会检查下载内容的实际图片格式；如果图床返回的格式与网址扩展名不同，保存名会使用实际格式的扩展名，且不会覆盖已有文件。有标题的相册或作品分别保存。普通下载会直连本机回环地址和 `NO_PROXY` 中指定的地址。

新建任务时也可以导入 CSV 或 XLSX，选择工作表、图片网址列与文件名列，预览前 5 行并按图片列建立子目录。每个单元格按一个网址处理；公式使用表格中保存的结果，不会执行公式。暂不支持旧版 XLS、加密工作簿和隐藏在单元格中的超链接；整个工作簿会先解析，包含不支持的单元格时会提示错误。文件最多 16 MiB，表格导入最多创建 10000 条任务。

在「下载」页打开「使用托管指纹浏览器登录抓取」开关后，提交的任务会通过专用浏览器登录并抓取动态页面；点「浏览器抓取」会先在专用浏览器中打开填写的网址。专用浏览器会通过隔离世界自动加载下载助手。网页出现可下载的图片后，点击页面右下角「下载到 tulai」，当前页就会加入下载队列。也可以复制当前网址，在新建任务中直接提交已打开的网页。Pinterest 搜索页采集当前搜索结果及最多八屏滚动加载的 Pin 图片。专用环境使用 Fingerprint 指纹浏览器，独立保存指纹和登录资料。浏览器模式采集当前页，只有同源图片请求可使用源站的非分区 Cookie。专用浏览器的网页访问和图片请求均使用直连，开启全局或系统代理时也可以启动。关闭软件后继续任务前，需要在专用浏览器重新打开目标页。

## 图片去重

左侧导航栏的「去重」。三步就够：拖图 → 选力度 → 开始。这一页与生图、洗图各自一份状态，互不干扰，也不占浏览器和引擎。

1. **拖图**：把图片或**整个文件夹**拖到页面任意位置（也可以点顶部「添加图片」「添加目录」）。同一张图重复拖入只收一次，解不开的文件直接跳过。文件夹只取这一层，不进子文件夹。
2. **选力度**：严格 / 均衡 (推荐) / 宽松三档，默认均衡，在左侧「相似度与输出设置」卡片切换。
   - 严格：只去几乎一样的图，同一张图重存、缩放、换了编码；
   - 均衡：再加上轻微裁剪；
   - 宽松：轻微改色、加了角标、同款不同图也可能并到一组。
3. **开始去重**：至少要有 2 张图片，点右上角的「开始去重」。输出默认是 `<设置里的输出目录>/去重/<YYYY-MM-DD>/`，也可以在左侧「相似度与输出设置」卡片的「输出：」一行点「更改」另指一个文件夹。跑完后右侧显示「去重报告」，点「打开」直达输出目录。

每组里分辨率最大的那张会被**复制**过去，原文件不动、不会被删；重复的图不复制，只写进 `重复报告.csv`（组号、保留、重复、差异位数）。重名时加 `_2`、`_3`，不覆盖已有文件。力度、输出目录和「允许纯色图」开关都存进配置库，重启还在。

判重口径都不看文件名和元数据：解码后像素摘要相同就是同一张；否则按 pHash（32×32 灰度做 DCT，取低频 63 位）的差异位数判近似。两张都没有纹理（纯色、纯白底、纯黑底）时默认还要求平均色接近，避免纯白底主图和纯黑底主图被判成同一张；要放宽这一条，打开左侧「相似度与输出设置」卡片中的「允许纯色图」。分组用并查集，A 像 B、B 像 C 时三张同组。两两比较是 O(n²)，一万张约五千万次异或，仍在几十毫秒量级。

## 批量重命名

左侧「批量重命名」页面提供五种模式：**查找替换**、**插入文本**、**序号重排**、**逐行编辑**和**AI 命名**。可以拖入或粘贴文件和文件夹，也可以用顶部的「添加文件」「添加目录」「递归目录」按钮添加；「递归目录」会递归加入其中的文件，直接添加的文件夹则作为一项改名。文件可以按名称、大小或修改时间排序，也可以通过行尾按钮上下移动调整顺序。

页面支持多条查找替换、插入文本或文件信息、自动编号、逐行手动编辑，以及通过视觉模型生成名称建议。逐行编辑时可把多行名称粘贴到某一行，依次填入后续项目；支持一键复制原名。编号支持阿拉伯数字、中文数字和英文字母。文件信息包括创建时间、修改时间、字节数、图片宽高和照片拍摄时间；拍摄时间目前读取 JPEG 的 EXIF。

执行前会显示新名称并检查冲突。目标已存在时不会覆盖；批内交换名称会先放到同目录的临时文件夹。执行中失败时会尝试恢复，若恢复受阻，错误信息会给出需要手动恢复的临时路径。程序意外中断时，可在源文件夹中显示隐藏文件，查找 `.tulai-rename-*` 并阅读其中的恢复说明；暂存文件保留原名。成功后可点击顶部「撤销上次」恢复原名；撤销时如果文件已被替换会停止。撤销记录只保存在当前运行中，添加或移除文件后清除。

普通规则默认保留扩展名的原有大小写；查找替换可勾选扩展名。查找框的模板可按位置或指定字符选取内容；手写正则用 `/表达式/g` 格式，采用 Go 正则语法，不支持 JavaScript 的后行断言等特性。AI 命名使用设置或本页模型配置中的自定义视觉模型 API 地址、Key 和模型名，只发送文件名及用户输入的要求。

## 图片编辑

「图片编辑」页采用三栏暗房布局（左胶片条、中央暗房预览画布、右侧参数面板），所有图像处理在本地纯 Go 引擎执行：

- **导入与多选**：点击顶部「选图」「目录」「从生图导入」，或直接拖拽 JPG / PNG / WebP / BMP / AVIF 图片与文件夹到窗口。左侧胶片条支持自动/手动折叠、`Shift` 与 `⌘/Ctrl` 多选，导出时若已多选则仅处理选中项。
- **交互暗房画布**：
  - **8 手柄交互裁剪**：启用「裁剪、尺寸与旋转」并处于裁剪模式时，可直接在原图上拖拽 8 个角/边手柄调整选区、拖动框体平移或重新框选（自动贴合锁定比例且不小于 8px）；支持比例预设、自定义 `宽 × 高`、推荐尺寸预设与「我的常用尺寸」，提供「裁剪」「等比缩放」「留白补满」「拉伸」四种尺寸模式、90° 旋转、水平/垂直翻转与「全批统一裁剪位置」。
  - **60fps 实时调色与原图对比**：在「色彩与清晰度」面板拖动「亮度」「对比度」「饱和度」「模糊」滑块或勾选「黑白灰度」时，画布本地实时呈现 60fps 过滤预览并平滑同步后端高清渲染（另支持「轻度锐化」）。开启顶栏「原图对比」（快捷键 `C`）后，可在画布上左右拖动 `5%–95%` 分屏帘（与工具栏滑块双向联动）对照处理前后细节。
  - **缩放与平移**：支持以光标为锚点的滚轮缩放（`10%–800%`）、按住 `Space`+左键或中键拖拽平移，以及暗房快捷键（`+`/`-` 缩放、`0` 适应画布、`C` 切换对比、`[`/`]` 左右旋转 90°、`↑`/`↓` 切换胶片）。
- **格式、配方与批量导出**：在「输出格式与目录」选择保持原格式或转码为 JPEG / PNG / WebP，配置压缩品质、文件名后缀与目标目录（同名输出自动追加序号，不覆盖原文件）。常用参数可通过顶部「配方」保存与套用；点击右上角「批量导出」执行批处理，失败项可点「重试失败」。

在「设置」页（`⌘/Ctrl+8` 或 `⌘/Ctrl+,`）按四个分类管理全局偏好，所有修改自动防抖并实时写入配置库：

1. **常规与输出**：即时切换「浅色模式」/「深色模式」，配置图片输出目录、自动编号开关与编号格式，以及网页下载默认目录、并发、重试与限速。

## 去水印

豆包生成图自动优先下载响应中对应的 `image_ori_raw` 原图；取不到时使用页面图片，并在保存前尝试修复已校准的角落水印。处理成功时结果目录直接保存去水印图。未匹配或处理失败时保留下载图，不会重新生成。

千问可在「设置 → 账号与任务」打开「去结果水印」，默认关闭。软件先保存网页下载的原图，再将匹配到的修复结果另存为 `提示词_01_去水印.png`；原图始终保留，队列每张生成图只显示一个最终结果。

当前适配 2026-10-22 校准的豆包、千问**正方形网页导出图**，包括千问左上角「AI生成」与右下角标记。通过归一化相关匹配固定字形，再按字形蒙版估算背景并补偿邻近细纹理。没有完整背景的真实值，复杂纹理、线条或主体上的水印可能留下痕迹，不能保证无损还原；平台改变样式后可能不再匹配。非方图、16 位高精度图、动画和超出处理大小限制的图片保留原样。

算法使用纯 Go 在本机运行，不额外上传图片，也不需要 Python、OpenCV、模型权重或新的 API Key。豆包原图提取参考了 [DoubaoRemoveMark](https://github.com/xiaoyu9308/DoubaoRemoveMark) 对 `image_ori_raw` 的使用；局部修复参考了 [LSJ Watermark Remover](https://github.com/RusianHu/lsj-watermark-remover/tree/9a2f5c0f4d64edaad704fdabfdc3264c5a2b999c) 的固定模板思路，以及 [remove-ai-watermarks](https://github.com/wiltodelta/remove-ai-watermarks/tree/b5021b0f6872b533f009a2cc50af9726f33e2177) 的定位、蒙版、局部修复流程。模板来源见 [`internal/images/watermarks/README.md`](../internal/images/watermarks/README.md)。

## 验证码求解后端

## 本地数据与迁移

macOS 打包版和源码版将配置库、`BrowserData/` 和默认输出保存到 `~/Library/Application Support/tulai/`；Windows 保存在 `%APPDATA%\tulai\`。Linux 普通可执行程序使用启动时的工作目录。输出目录可以在设置中更改。

每个受管账号使用独立随机目录（位于 `BrowserData/Fingerprint/` 下），重命名和同名账号不会共用资料，每个账号目录保存自己的 `.tulai-fingerprint.json`。

macOS 上若旧版账号资料仍在项目目录，请在首次启动新版前退出 tulai 和其内置浏览器，然后在项目目录运行 `python3 scripts/migrate_macos_data.py`。迁移会复制并校验数据库、浏览器资料及旧默认输出目录，保留原项目资料作为备份；若应用目录已有其他独立数据则停止，不会覆盖。自定义输出目录和其他历史源文件保留原路径。

配置库位于数据目录下的 `database/config.db`。已有配置使用旧目录名时，请先退出应用，再将 `数据库/` 重命名为 `database/`。

## 追查任务

每次开跑会生成一个 `run_id`。点击左下角设置上方的「日志」或按 `⌘/Ctrl+J` 可在悬浮「运行日志」抽屉中按级别、来源和关键词实时检索，并可「复制」或「导出」当前日志。持久化日志文件保存在数据目录的 `logs/` 下，按天切片（`tulai.YYYYMMDD.log`），保留最近 7 天，过期自动清理。同一条也打到 stderr。

每一行按「时间、级别、模块、事件、详情」排开，空字段自动省略，不再刷出 `task_id=0`、`port=0`、`error=""`。方括号里是平台/账号、端口和阶段（`stage`），行尾保留 `task_id` 和 `run_id` 供检索；`task_id` 就是队列序号（日志里的 `#3`）。`stage` 是 `queue`、`assign`、`open`、`upload`、`submit`、`wait`、`detect_done`、`extract`、`download`、`save`、`probe`、`login` 之一，普通界面日志不显示默认的 `log` 阶段。

```text
2026-11-13 16:40:12.345  成功  [千问/千问1:9338 · submit]  #3 发送完成  (1.234s · 4 张 · 10.0 KiB)  task_id=3 run_id=20261113T164000
```

进入数据目录后，只看第 3 条（当天的切片）：

```bash
grep 'task_id=3' logs/tulai.$(date +%Y%m%d).log
```

同一批再加 run_id：

```bash
grep 'run_id=20261029T160900' logs/tulai.*.log | grep 'task_id=3'
```
