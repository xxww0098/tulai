REA 的 PyInstaller 归档记录为 `ev_a312ece815a618d7827912b694d486229e9742534971c67079210e681f4f571e`，主模块字节码记录为 `ev_4d0116d28b655a2d44660b43889121e0f24d48e37b5bd2889a90a058f19244f1`。随后使用 Python 3.13 静态反汇编主模块；没有运行参考程序。

配置中的三个列表规则分别是亚马逊、eBay 和亚马逊法国。它们读取商品列表中的图片、标题、商品链接及下一页；列表模式把这些信息保存到数据库。程序还提供亚马逊商品详情采集和 Temu 搜索采集：Temu 监听用户浏览时的响应，读取 `result.data.goods_list` 中的图片和标题，并不主动翻页。一个隐藏的 `de` 入口读取亚马逊商品页的搭配商品。

当前下载器的对照范围：

- 亚马逊 `/s` 搜索及筛选结果：按商品保存列表主图，尝试放大，并在放大地址返回 404 时使用页面原图。跟随站点提供的下一页并保留搜索条件。亚马逊美国站公开搜索的两页 HTML 已连续回放，识别 93 张图片；一张放大图已实际下载。法国站匿名请求返回 HTTP 202 空响应，尚未实测结果列表。HTML 采集不判断外部样式或图片加载状态。
- eBay `/sch/i.html` 和 `/sch/<分类编号>/i.html`：按商品保存列表图片，尝试 `s-l1600` 并在 404 时回退到原图，跟随站点提供的下一页。当前公开搜索请求返回 HTTP 403，列表解析和分页仅通过参考配置及合成测试验证；其他列表路径尚未确认。
- Temu 搜索：在下载浏览器中完成验证并加载商品后，采集当前已加载、可见且能匹配商品编号的主图。可从 Temu 首页进入搜索，或直接打开搜索网址；需要更多结果时先在浏览器中滚动加载，再开始采集，最多读取 1000 个商品。普通 HTTP 响应是脚本空壳，公开浏览器测试遇到安全验证；目前仅按官方页面脚本和合成浏览器页面验证，未验证真实搜索结果。
- 亚马逊、eBay 和 Temu 商品详情已有独立采集；各自限制见 [AllPicDownloader 对照记录](allpicdownloader-ida.md)。
- 亚马逊隐藏 `de` 模式尚未实现。两个公开商品页的静态 HTML 均未出现其搭配商品容器，无法确认当前模块及“加载更多”的行为；普通商品采集不会主动混入搭配商品。

亚马逊和 eBay 搜索最多读取 100 页，遇到验证、限流或未能确认的下一页时会提示并保留已找到的结果。网站可能更改页面结构；需要登录或验证的页面须由用户在下载浏览器中完成。
